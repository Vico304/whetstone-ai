# Whetstone 设计核心

> 本文档是整个项目中心思想的最小完整表达。规范性约束的完整版本见 [consensus.md](consensus.md)，冲突时以后者为准。

## 1. 问题

传统阅读和普通 LLM 问答产生同一类失败：**看过很多，调用不出**。学习者积累了熟悉感，却没有形成可解释、可迁移的心智模型；LLM 能生成流畅解释，但缺少来源约束时，错误会被长期沉淀为"已学会的知识"。

项目要回答的不是"读到第几页"，而是：

> 学习者现在真正理解了什么？哪些概念不稳固？下一次 8 分钟最值得做什么？

## 2. 立场

市面上的学习软件优化"无摩擦"，本项目站在相反一侧。学习科学的核心结论（desirable difficulties）是：让学习变流畅的手段大多损害长期保持，让检索变费力的手段大多增强它。因此：

- **不做摘要器**。"文件 → 摘要 → 闪卡"是立项时明确要避开的失败形态；
- **主动重建是核心学习行为**。学习者在隐藏参考的条件下，用自己的话解释概念、建立有类型有方向的关系——这是检索练习（g ≈ 0.5–0.6）与自我解释（g ≈ 0.55）的叠加，摩擦即机制；
- **学习效果优先于图谱完整和自动化程度**。图谱是工具不是目标。

## 3. 三层架构

系统同时维护三种知识表示，任何一方都不是天然权威：

```text
                原始材料
                    │
                    ▼
        原文证据层 SEL（材料说了什么）
        不可变来源单元 / 版本 / 定位
            ┌───────┴───────┐
            ▼               ▼
    机器参考图 MRG      阅读与学习活动
    （机器如何组织）         │
                            ▼
                    学习者重建图 LRG
                    （学习者真正能外显什么）
            │               │
            └───────┬───────┘
                    ▼
                差异比较 → 回到证据裁决
                    ▼
        学习反馈 / 机器修订 / 人工裁决
```

- **SEL**：不可变、版本化的原文单元，裁决一切分歧的地基；
- **MRG**：LLM 生成、证据验证的参考结构——可审核、可修订，**不等于标准答案**；
- **LRG**：学习者在特定时间、特定提示条件下重建的理解——重建本身就是学习。

双图差异是整个设计的支点，它同时承担四重功能：**学习诊断**（学习者漏了什么、错在哪）、**图谱质检**（学习者可能发现机器的错误）、**忠实度验证**（双方都要回到原文）、**学习决策**（差异决定下一步活动）。

## 4. 学习闭环

```text
选定可承受的局部子图（单次新概念 ≤ 4）
  → 阅读来源单元
  → 隐藏参考，学习者预测/解释/建立关系
  → 保存首次原始重建（不覆盖）
  → 与 MRG 比较，分歧回到原文
  → 针对性追问与修订
  → 延迟后以更少提示再次重建
  → 更新学习者状态
```

三条贯穿性原则：

1. **提示渐隐**：全概念名 → 少数锚点 → 无提示 → 迁移情境。脚手架必须随水平撤除（expertise reversal effect）；
2. **证据等级链**：即时识别 < 即时复述 < 延迟解释 < 延迟关系重建 < 新情境迁移。系统信任延迟与迁移证据，不信任即时表现；
3. **首次重建前不展示参考答案**——越过这条线，主动回忆就退化为识别和抄写，即被证明低效的形态。

## 5. 关键约束

- **五类支持类型**贯穿所有知识输出：`explicit / entailed / pedagogical_inference / external / unsupported`。教学推断不得伪装成作者原意；
- **不覆盖**：学习者回答不得改写机器参考，机器参考不得改写学习者原始回答，修订产生新版本；
- **职责分离**：同一次无记录推理不得同时完成"生成、审核、改写、发布"。确定性检查交给脚本，语义判断交给模型，高影响歧义上报用户；
- **允许不确定**："原文模糊""无证据""暂不判断"是合法状态，不为图谱完整伪造确定性；
- **多维状态**：掌握度不压缩为单一分数，回忆强度、解释质量、关系理解、信心校准分开表示。学习者自评信心只是诊断信号，不是掌握证明。

## 6. 当前状态与边界

核心教学闭环已实现为跨宿主技能插件（见 [`plugin/`](../plugin/)，同一技能目录适配 Codex、Claude Code 与 DeepSeek Harness）并在日常自用：材料 → 问题链课程（问题 → 方案 → 新问题）→ 逐节预测、重建、信心标注、针对性追问 → 延迟变式检索。

**尚未验证的核心机制**：双轨比较至今未真正运行——学习者重建仍以自由文本保存，未结构化为图，差异分类器不存在。这是下一里程碑（见 [roadmap.md](roadmap.md)）。

**明确不追求**：完全自治的多 Agent 网络、适用所有学科的唯一关系体系、多本书无差别合并、单一掌握分数、把学习者作答当免费标注劳动。

**开放问题**（不得当作已证明结论，完整清单见 consensus.md §17）：提示渐隐降低多少回忆难度；单次活动的认知负担上限；如何避免比较器系统性偏向机器答案；**双轨机制的学习收益能否覆盖其交互成本**——最后这条是项目的生死问题。
