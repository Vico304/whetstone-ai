> 方法：2026-08 联网调研同类产品实证数据、学习科学元分析、LLM 评分可靠性研究，逐层对照现有方案给出「可采用 / 需优化 / 建议替换」判断

## 0. 结论速览

现有方案的**理论根基比预期更扎实**——核心设计"从记忆中重建概念图"恰好落在学习科学两大高效应量策略（检索练习 + 自我解释）的交集上，且规避了 Karpicke & Blunt (2011) 对传统概念图学习的著名批评。三层证据结构（SEL/MRG/LRG）在防幻觉、防覆盖上的设计也与 2024–2026 年对 LLM 学习者建模的批评性研究结论一致。

但调研同时暴露出四个方案未充分处理的风险，按严重程度排序：

1. **参与度是第一死因**（Khanmigo 两年期 RCT 的核心教训），而方案几乎全部篇幅在讲"学习正确性"，对"让人持续用下去"着墨极少；
2. **双轨机制的交互成本无先例验证**，最接近的先例（Kit-Build）用的是封闭式重组而非自由重建，方案直接从最高难度形态起步；
3. **LLM 评分可靠性有硬上限**——人类评分者本身分歧大的维度 LLM 也不可靠，方案的 Comparator 需要更强的防偏差工程；
4. **先修关系抽取的自动化精度不足**（概念抽取尚可、先修边明显更难），方案已假设"需人工修正"，方向正确但低估了修正量。

一句话总结：**方案的"学习正确性"设计可以基本保留，需要补的是"可持续性"设计；实施顺序建议从方案默认的最高形态改为渐进爬坡。**

## 1. 外部证据基准

### 1.1 同类产品的实证表现（2024–2026）

| 产品/系统 | 做法 | 实证结果 | 证据等级 |
|---|---|---|---|
| Khanmigo | GPT 辅导 + Khan 练习体系 | 2026 年 NBER 两年期 RCT（田纳西 18 所中学）：数学提升仅 0.06–0.08 SD/年，与无 AI 的普通练习相当；中位学生仅 1/3 练习日使用，出错后仅 17% 场次求助 | RCT，强 |
| LearnLM / Study Mode / Claude Learning Mode | 提示工程实现"教学模式" | TeachLM 研究：三家行为高度趋同，常见缺陷是给答案、默认选择题、忽略学习者上下文；答案准确率 97.3% 但教学合理性仅 56.6% | 独立评测，中强 |
| Duolingo | Half-Life Regression 建模记忆半衰期 | 召回预测误差降 45%，日活 +12% | 厂商论文（ACL 2016），中 |
| Math Academy | 手工构建先修图谱 + 图上诊断 | 无独立 RCT | 厂商宣称，弱 |
| Anki / RemNote | FSRS 间隔算法 | srs-benchmark 约 7 亿条复习记录：FSRS-6 对 99.5%+ 用户优于 SM-2，等留存下省 20–30% 复习量 | 大规模基准（非 RCT），中强 |
| Kit-Build（广岛大学） | 专家图拆成部件让学习者重组，命题级自动 diff | RCT 显示显著提升阅读理解 | RCT，强；但为封闭式重组 |

**对本项目最重要的三条：**

1. Khanmigo RCT 证明"AI 能力不是瓶颈，参与度才是"。个人自用项目风险同构：系统再正确，如果单次活动摩擦太大，连续使用就会中断，一切学习者建模都失去数据来源。
2. Kit-Build 是"双图 diff 诊断"的最直接先例且有效，但它给定部件、只要求重组。方案要求的"自由回忆 + 自造概念 + 有类型关系 + 写理由"是显著更高的认知与操作负担，**没有任何先例在这个难度上验证过可持续性**。
3. "LLM 对学习者自由绘制的概念图做评分/反馈"在 2025 年系统综述中被确认为研究空白——方案做的是没人验证过的事，这既是机会也意味着不能引用任何现成结论保证可行。

### 1.2 学习科学效应量核对

方案依赖的认知科学结论，逐一核对元分析数据：

| 方案假设 | 证据 | 判定 |
|---|---|---|
| 检索练习优于重读 | Adesope et al. 2017 元分析（272 效应量）：g = 0.51 vs 重学，g = 0.61 vs 全部对照；反馈增强效应；保持间隔 1–6 天时效应更大（g = 0.82 vs <1 天的 0.56） | **强支持** |
| 自我解释有效 | Bisra et al. 2018 元分析（69 效应量）：g = 0.55；但"解释自己的知识状态"类元认知提示效果较差 | **强支持**，注意元认知型提示的例外 |
| 学习者构建概念图有价值 | Schroeder/Nesbit/Adesope 2018 元分析（142 效应量）：概念图整体 g = 0.58，**构建**（g = 0.72）显著优于**研读**（g = 0.43） | **强支持** |
| 概念图 vs 检索练习之争 | Karpicke & Blunt 2011（Science）：检索练习优于概念图绘制；O'Day & Karpicke 2021：概念图+检索不比纯检索好但更费时。**关键调和点：方案要求"从记忆中重建"，这本身就是检索练习**，与被批评的"照着书画图"不是同一活动 | **方案设计恰好站在正确一侧**，但必须严守"不看材料重建"这条线，一旦允许翻书就退化为被证伪的形态 |
| 延迟重建优于即时重建 | 延迟 JOL 效应（Nelson & Dunlosky 1991；Weaver & Kelemen 1997）：延迟判断校准接近完美，即时判断被流畅性错觉污染；Adesope 2017 也显示 1–6 天保持间隔效应更大 | **强支持** |
| 学习者自评信心只作诊断信号不作掌握证明 | 流畅性错觉与过度自信文献一致；延迟可改善校准 | **强支持**，方案此处设计正确 |
| 提示渐隐（全名→锚点→无名→迁移） | expertise reversal effect（Kalyuga）：对新手有效的脚手架对熟练者有害，故脚手架必须随水平撤除 | **方向有强支持**，但具体的四档划分是方案自创，档位切换时机是开放问题（方案已如实标记） |
| 单次活动控制在"一个中心概念+少量相关概念" | Cowan (2001/2010)：工作记忆约 4±1 chunks（非 Miller 的 7±2）；element interactivity 决定实际负荷 | **强支持**，建议把"少量"明确为"新元素不超过 4 个" |
| 间隔复习 | Cepeda et al. 2008（N>1350）:最优间隔约为保持目标的 10–20%（目标越远间隔越长）；FSRS 已把此类规律工程化 | **强支持**，但结论是"直接用 FSRS，勿自研遗忘模型" |

### 1.3 LLM 能力边界的批评性研究

- **LLM-as-judge 已确认偏差**：position bias、verbosity bias、self-preference（偏好自己生成的/低困惑度文本，幅度可达 -38% 到 +90%）。教育评分场景可靠性区间极宽：约束性短答题 QWK 可达 0.95+，开放性作答低至 r = 0.38。**规律：人类评分者本身分歧大的维度，LLM 也不可靠——模糊 rubric 会被传导而非被解决。**
- **LLM 学习者建模的时间一致性缺陷**：2025 年末的实证研究（arXiv:2512.23036）指出 LLM 无法跨时间一致地追踪学习者知识状态。方案用结构化 LearnerConceptState 而非"让 LLM 记住用户"，与该结论一致，是正确决策。
- **知识图谱自动构建精度**：LLM 零样本先修预测与专家标注已高度一致（2025），但课程知识点抽取 F1 约 0.77（低召回为主）；共识是概念节点抽取中等可靠、先修边明显更难。公开基准：LectureBank、AL-CPL。

## 2. 逐层评审

### 2.1 三层结构（SEL / MRG / LRG）——可采用，局部优化

**可采用的部分（外部证据支持）：**

- SEL 不可变证据层 + 版本化：与 Graph RAG 幻觉研究的结论（自动图谱仍会幻觉、需可回溯验证）一致。这是方案对抗"错误知识长期污染"的核心手段，保留。
- MRG/LRG 逻辑分离、互不覆盖：与"LLM 时间一致性差"的批评互补——学习者状态放在结构化数据里而不是 LLM 记忆里，正确。
- support_type 五分类（explicit/entailed/pedagogical_inference/external/unsupported）：比单一置信度分数严谨，且"先修边默认是教学推断"与抽取精度研究吻合（先修边确实最不可靠）。

**需优化的部分：**

1. **LRG 的起步形态过重。** 方案第一版就要求自由回忆 + 有类型有方向有理由的关系。建议引入 Kit-Build 式的**封闭重组作为爬坡前段**：先给概念卡片让学习者连线归位（有 RCT 支持、评分可完全确定性），表现稳定后再过渡到自由重建。这不与"提示渐隐"冲突，而是把渐隐的起点再往前挪一档，同时解决了冷启动期"LLM 评自由重建"最不可靠的问题。
2. **关系"必须写理由"应改为分层要求。** 每条边都写理由是 O'Day & Karpicke 警告的"费时不增益"高危区。建议只对中心概念的 1–2 条关键边要求理由（自我解释 g=0.55 的收益集中在因果/机制类推理），其余边只选类型和方向。
3. **Comparator 防偏差需要具体工程约束**，方案只提了问题（开放问题 6）没给对策。至少应写入共识：比较时交换 MRG/LRG 呈现顺序取均值；Comparator 使用与 Extractor 不同的模型或至少不同提示链（防 self-preference）;概念级 rubric 先行拆分再判断,不做整段相似度。

### 2.2 知识图谱构建管线——可采用，调低自动化预期

- 候选→验证→策展的分权流程：保留。与"两个模型给出相同结论不等于事实"的原则一致。
- **需修正的预期**：F1≈0.77 意味着每章会有可感知的漏检。方案假设"人工/使用中修正"，但应把修正做成学习活动的副产品而不是独立维护任务（用户在重建中新增的概念本来就是 MRG 召回缺口的信号——方案 8 节的裁决表已有此机制，应明确把它当作**主要**修正通道而非兜底）。
- 材料导入六层管线与 PDF 四级分流：技术判断正确，无需改动。"是否加 Python 解析服务"的决策建议维持文档结论——学习闭环验证前不加。

### 2.3 学习闭环设计——大部分可采用，两处修改

- 完整循环（读→隐藏参考→重建→比对→反馈→修订→延迟再建）：**结构有强证据支持**（检索练习 + 反馈增强 + 延迟效应三者叠加）。
- "首次重建前不展示参考答案"：正确且必须严守，这是方案区别于被证伪形态的关键线。
- **修改一：明确元素数量上限。** 把"少量直接相关概念"量化为"单次新概念 ≤ 4"（Cowan 上限），已学概念作为锚点不计入。
- **修改二：自我解释提示避开元认知型。** Bisra 元分析显示"解释你对 X 的理解程度"这类提示效果差，应使用"为什么 A 导致 B""如果去掉 X 会怎样"这类推理型提示。方案 5.1 的设计已经偏向推理型，写入共识固化即可。

### 2.4 学习者模型与间隔复习——方向正确，明确选型

- 多维状态（回忆强度/解释质量/关系理解/应用/信心校准）优于单一分数：与"评分构念研究"一致（连边得分测术语记忆、结构得分测理解——不同指标测不同东西，压缩成一个数会丢诊断信息）。保留。
- **明确建议：遗忘/复习调度直接采用 FSRS，不自研。** 7 亿条记录的基准优势 + 开源实现成熟，自研没有任何胜算且不是项目差异化所在。方案任务树 6.4"设计遗忘与复习状态模型"应改为"集成 FSRS 并定义概念级复习项的映射"（概念、关系、命题分别作为独立复习项还是聚合项，这才是本项目真正要回答的问题）。
- 掌握度估计的学术参照系建议从 BKT 转向 **PSI-KT**（2024，结构+贝叶斯学习者建模，与本项目"先修图+状态推断"思路最接近），作为后期升级方向；第一版维持规则式。

### 2.5 碎片时间与调度——理论可采用，但这是方案最薄弱的一层

方案对 Curriculum Engine 的定义（状态+图谱+时间预算→下一动作）没有问题，但 Khanmigo RCT 的教训是：**决定成败的不是推荐算法的精度，而是单次会话的启动摩擦和中断韧性**。方案的 Context Reconstruction 设计（显示"你正在理解什么/上次的疑问"）方向正确，但建议把优先级提到与知识图谱实验同级：

- 恢复卡片 + 一个 retrieval 问题的"30 秒重启"体验应该在第一个章节实验里就实现，而不是等 Phase 5；
- 每次会话结束必须有一个可感知的结构增长反馈（方案 9.4 已有此设计，应从"后期可视化"提前为"第一版必做"）；
- 建议增加一个方案完全没有的度量：**恢复成本**（从打开系统到进入有效学习的秒数）和**连续使用天数**，作为与学习效果并列的第一等指标。

### 2.6 Agent 权限与流程——可采用

分权模型（Extractor 只提候选/Verifier 只附判断/Curator 才发布）无需修改。补充一条工程建议：Verifier 与 Extractor 至少异构提示链（见 2.1 第 3 点），把"防自偏好"从原则落为约束。

## 3. 替代方案探索结论

调研中系统寻找了可能整体替代双轨设计的路线，结论如下：

**路线 A：纯检索练习 + FSRS 闪卡（Anki 流派）。** 证据最充分、工程最简单，但只覆盖离散知识点，不解决"关系结构与心智模型"目标，且 LLM 自动生成闪卡质量已被多产品验证平庸。**不建议替代，但它提示：方案里离散事实类知识不必走双轨重建，直接进闪卡+FSRS 更省力——双轨应保留给机制、因果、结构类知识。**

**路线 B：Kit-Build 式封闭重组。** 有 RCT 支持、可确定性评分、认知负担低。**不建议整体替代**（它测不出自由回忆，天花板低），**但建议作为双轨的第一档形态吸收进方案**（见 2.1）。

**路线 C：纯对话式辅导（Study Mode 流派）。** TeachLM 数据显示当前 LLM 教学模式行为平庸且无学习者状态持久化，正是方案批判的"摘要器+聊天机器人"。调研证据反而强化了方案的判断。**不采纳。**

**路线 D：手工先修图谱 + 程序化诊断（Math Academy 流派）。** 图谱质量高但构建成本对个人自用不可行，且无独立效果验证。**不采纳，但其"图上缺口诊断"逻辑与方案 Curriculum Engine 一致，无冲突。**

**综合：不存在整体更优的替代方案。** 方案的独特组合（自由重建=检索练习+自我解释+结构化诊断，受证据层约束）在产品与研究版图上确实是空白点，理论上站得住。真正的风险不在方向而在剂量——每一处"更严谨"的设计都在增加交互成本，而参与度证据表明成本会复利式杀死系统。

## 5. 对首个章节实验的修订建议

综合上述，建议首个端到端实验（任务树 P0）的范围调整为：

1. 一个真实想学的章节 → MRG（接受 F1≈0.77 的现实，人工补一次）;
2. 知识分流：离散事实 → 闪卡 + FSRS；机制/结构类 → 双轨重建;
3. 重建爬坡：第 1–2 次用封闭重组（给概念卡连线），之后进入 anchor_names 自由重建;
4. 单次活动新概念 ≤ 4，只对关键边要求理由;
5. 第一天就实现 30 秒恢复卡片 + 会话末结构增长反馈;
6. 记录四类数据：延迟重建表现、LLM 评分与自评的分歧、恢复成本、连续使用天数;
7. 三周后回答方案真正的生死问题（开放问题 10）：**双轨的诊断收益是否值得它的交互成本。**

## 7. 2026-09 补充：对 v2 设计决策的证据核对

v2（见 `consensus.md` §21.1）作出六项新决策。逐项核对可引用的证据：

| v2 决策 | 相关证据 | 判定 |
|---|---|---|
| LRG 只追加、不可编辑，错误回答本身作为复习资产 | 错误驱动学习：Kornell, Hays & Bjork 2009——检索失败后再学习优于直接学习；Metcalfe 2017（*Annual Review of Psychology*）综述——主动犯错并得到纠正的学习优于避免犯错；hypercorrection（Butterfield & Metcalfe 2001）——高信心错误被纠正后保持更好 | **强支持**。条件：纠正必须紧跟暴露；复习题需同轮闭环 |
| LRG 对学习者不可见，旧回答以去主体化匿名命题出题 | 无直接文献。相关：自我评价情绪对学习动机的影响（自我决定理论一类）；评价"他人"主张时所有权偏见更弱属于合理推论 | **无直接证据**。所有权感消失是否削弱 hypercorrection 是新开放问题（§17.14） |
| MRG 分四层，`rationale / principle` 永不展示，只用于出题 | Schwartz & Bransford 1998 "A Time for Telling"（*Cognition and Instruction*）——先对比案例再讲解，讲解被理解为洞见；SOLO taxonomy（Biggs & Collis 1982）对四层的结构对应；Polanyi 1966 默会知识 | **方向强支持**。四层的具体切分是方案自创；模型判定到达层的可靠性未验证（§17.13） |
| 受信领域 MRG 默认可信，单向诊断 | 无学习科学证据可直接支持或反对——这是范围决策。风险来自 LLM 抽取而非材料：先修边抽取精度低于概念抽取（arXiv:2507.18479）；关系方向与粒度错误在 §1.3 已述 | **作为范围决策可接受**；支持类型分级与 `weak_reference` 类别是必要的保险 |
| 跨课概念注册表，变式题替代前置诊断 | 间隔效应（Cepeda et al. 2008）——把复用变成延迟检索符合最优间隔方向；概念对齐属于实体消解 / 本体对齐，一般情形无解，个人规模 + 人工确认可行 | **机制有支持**，工程精度未验证（§17.16） |
| 可视化按当前掌握估计（证据等级 × 时效）着色，不按错误次数 | 与 §1.2 延迟 JOL、流畅性错觉一致：即时证据不代表掌握；FSRS 类模型说明时效必须建模。以错误次数着色会与 hypercorrection 结论矛盾 | **支持** |
| 协议阶段化、有效规则集 ≤ 60 行、模型分层 | 多约束指令遵循基准（IFEval 一类）显示遵循率随约束数下降；Liu et al. 2023 "Lost in the Middle" 显示长上下文中段信息被忽略 | **支持**；阶段化对连贯性的代价未测（§17.17） |
