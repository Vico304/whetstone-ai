# 怎么用（引导）

目标：两轮往返之内，让学习者带着一条可粘贴的调用语句离开。不讲设计文档，不列功能清单。

## 第一轮：一段话 + 环境检查 + 三个问题

**一段话**（原样可用）：

> Whetstone 会把你的材料改写成"问题 → 方案 → 新问题"的路线，然后逐节让你先预测、再合上材料用自己的话解释、自评信心、被追问。它记录你每一次回答（包括错的）来安排以后的复习。两条规则你要自己守：答题前合上材料；不要去看进度文件和日志。

**环境检查**（静默执行，只报异常）：

```bash
python3 --version                                    # 需要 ≥ 3.9
python3 "<learn 技能目录>/scripts/validate_lesson.py" --help > /dev/null && echo ok
ls <工作区>/store/store.json 2>/dev/null             # 有 → 知识库已初始化
```

**三个问题**（一条消息问完，学习者可以只答一部分）：

1. 材料在哪？（文件路径、目录、或"还没有"）
2. 想学到什么程度？——**完整**（每节都重建、追问）还是**快速**（只走主线，回答方向对就继续，最后整体重述）；
3. 要不要跨课累积？（要 → 指定一个知识库目录，以后每门课都会用它记概念掌握与时效）

## 第二轮：按回答分流

- 材料是**一个目录或多条路径** → 转"规划"（先目标与背景，再扫描、切计划）；
- 材料是**单个文件**：≤ 30 KB 直接给 `learn` 调用语句；更大则转"规划"按标题切；
- **还没有材料** → 说明适合的材料类型（教材一章、规范一章、代码库的一个子系统），不推荐具体书目，结束。
- 要知识库 → `python3 "<learn 技能目录>/scripts/store_init.py" init --store <目录> --domain-root <学科>`。

## 交付

给两条可粘贴的语句（路径填实）：

```text
/whetstone:learn 学习 <材料路径>，知识库目录 <目录>，课程目录 <工作区>/courses/<名>/。
我希望学完后能 <目标>。
```

并预告第一节会发生什么：先问目标与背景（一轮）→ 出大纲请你确认模式与取舍 → 生成各 unit 文档 → 前置诊断一次一题（"不知道"是合法答案）→ 第一节只给"当前问题"让你预测。想先看或改大纲：`/whetstone:outline courses/<名>/`。
