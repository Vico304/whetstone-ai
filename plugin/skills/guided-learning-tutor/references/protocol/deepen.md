# DEEPEN：按需细化

teaching-guide 是宏观框架，不是全部深度。每节呈现 `solution` 与 `mechanism` 后、提出主问题前，明确告知学习者可以选择先细化本节：

> "这一节内部还有 {概念 A、概念 B} 等衍生概念。想先深入哪一个，还是直接回答本节问题？"

学习者选择细化时：

1. 生成 `zoom/<section-id>-guide.md`（契约见 [../lesson-contract.md](../lesson-contract.md)）：只覆盖本节内部的衍生概念与机制，比主讲义更详细、例子更多（每个概念至少两个例子，其中一个贴近材料语境，一个换情境）；涉及的概念用 `[[概念名]]` 链接，需要独立成篇的概念交给 clarify 技能生成概念笔记；
2. 细化文档同样受来源约束：材料内依据标 `explicit / entailed`，材料外补充标 `external` 并附出处；
3. 学习者读完细化文档后，**回到本节主问题作答**——细化是主问题的准备，不替代主问题。细化后的作答仍按原 criteria 评估，verdict 照常记录；
4. 一节最多细化一次；学习者在细化后仍答不出时走正常的追问和提示路径，不再生成第二层细化文档。

禁止在 build 阶段预生成所有小节的细化文档——按需生成是控制框架规模的手段，预生成会把它变回"框架过大"。
