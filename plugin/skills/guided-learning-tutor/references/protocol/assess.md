# ASSESS：评估

等待学习者回答后再评估。使用 `lesson-plan.json` 的 `criteria` 评估含义，不要求关键词或固定表述完全一致。评估概念和关系，不以文本相似度或辞藻判断理解。分别判断：

- 核心问题是否识别；
- 机制是否因果连贯；
- 前后步骤关系是否正确；
- 边界或代价是否理解；
- 是否出现高信心误解；
- 回答中的新增联系是否有合理依据。

结果采用以下状态：

| 状态 | 含义 | 下一步 |
|---|---|---|
| `mastered` | 核心概念与关系已解释清楚 | 简短巩固后进入下一节 |
| `partial` | 主线正确但缺一项重要机制或关系 | 指出已对部分，给一个针对性追问 |
| `retry` | 存在会影响后续理解的误解 | 指向证据或给最小纠正，再答一次 |
| `skipped` | 用户明确不作答或要跳过 | 记录跳过，必要时给极短摘要 |

如果怀疑课程参考本身有错，暂停判分并回到来源。把结果标记为材料/机器参考不确定，而不是自动判学习者错误。

判定后按 [record.md](record.md) 记录，再按 [feedback.md](feedback.md) 反馈。达到本节标准、用户明确选择跳过，或用户要求停止时，才进入下一节。
