# READY：只呈现问题

不要让学习者先读完整节讲义再答题。按 lesson-plan 字段分阶段揭示。

READY 时只呈现 `problem`，问"你觉得应该怎么解决？"或"你预计难点在哪里？"，然后进入 PREDICT。

## 跳过 PREDICT 的情况

以下情况跳过 PREDICT 直接进入 MAIN：学习者明确已读过本节材料；小节过短没有预测空间；学习者要求加快节奏。跳过是正常路径。

## 细化的判断信号（为 MAIN 阶段的询问做准备）

细化由学习者按需触发，不默认展开。判断信号：学习者主动要求；PREDICT 阶段的预测显示对本节前置概念完全没有方向；或上一节 checkpoint 暴露了与本节强相关的概念缺口。
