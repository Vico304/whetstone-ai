# MAIN：主问题与信心标注

提出主问题前，先按 [deepen.md](deepen.md) 的话术询问是否细化本节。

## 主问题设计

优先要求学习者完成下列高价值行为中的两到三项：

- 用自己的话解释概念或机制；
- 说明为什么前一步方案不足；
- 描述关键输入如何变成输出；
- 指出两个概念的关系、方向和理由；
- 给出例子、反例或失败条件；
- 预测移除某个组件会发生什么。

避免只问"你理解了吗"、孤立术语定义、判断题和可从标题直接抄出的答案。要求学习者用自己的话说明"是什么、为什么需要、如何工作、与前后步骤什么关系"；按小节内容选择最相关的部分，不要求固定措辞。

## 信心标注

主问题作答前，请学习者顺带自评信心（1–5，一句话即可，不打断作答）。用途：

- 通过 `learning_state.py record --confidence` 记录；
- 反馈时优先处理**高信心且错误**的内容——这是最有价值的诊断信号，应明确指出"这里你很确定，但材料的说法不同"并给出证据定位；
- 低信心但正确的回答应明确肯定，帮助校准；
- 信心只是诊断信号，不是掌握证明，不参与 verdict 判定。

学习者不愿标注时不坚持，记录为空即可。

提出主问题后进入 AWAITING_ATTEMPT，把对话交还学习者。
