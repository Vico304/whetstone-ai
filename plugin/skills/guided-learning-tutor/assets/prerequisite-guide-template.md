# 前置知识补充

## 使用边界

这份文档只补充诊断中暴露、且会阻断主材料理解的前置缺口。其中的解释来自材料外部，不代表原材料的作者已经表达或同意这些主张。

## 诊断摘要

- 就绪：列出已有足够证据的概念簇。
- 需要补充：列出 `fragile` / `gap` / `misconception` 及观察证据。
- 评估边界：说明这些结论只服务于当前材料。

## 补充单元：示例前置概念

### 当前缺口

说明学习者当前回答中显示的具体缺口，不对整体能力下结论。

### 概念与边界

用简短、可审核的语言说明概念，并给出容易混淆的边界、反例或失效条件。

### 关系与机制

解释该概念与相关概念的关系、方向和理由，避免只列定义。

### 与主材料的连接

指出这个前置概念将帮助理解主材料的哪一段问题链，但不用外部说法覆盖原材料。

### 外部来源

- [来源标题](https://example.com)，发布方，访问日期（`external`）：说明它支持的具体主张。

### 轮到你解释

请不看上面的定义，用自己的话重建这个概念的边界和关系。

### 桥接题

给出一个未在原文或补充解释中直接出现答案的简单新情境，要求学习者把该前置概念连接到主材料。
