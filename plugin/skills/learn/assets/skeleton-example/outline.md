## 1. 总体问题

在一台由他人控制的机器上运行代码时，如何让远端相信代码没有被篡改、数据没有被窥视？

系统地图：硬件隔离出受保护区域 → 加载时度量 → 度量 + 硬件签名交给远端 → 远端核对后才交付密钥。

## 2. 问题链

| # | Unit | 当前问题 → 方案 | 状态 |
|---|---|---|---|
| 1 | 隔离：为什么特权软件也不能看 | 特权软件可能被攻破 → 硬件划出特权软件也看不见的区域 | 待学（先做原理探测） |
| 2 | 度量与证明：让远端相信里面装的是什么 | 远端不知道里面是什么 → 硬件对内容做哈希并签名 | 待学（先做原理探测） |

## 3. 全部概念与落点

**Unit 1**
- core：Enclave —— 落点 `occlum/docs` · Overview / enclave
