# 从“whetstone”到 Guided Learning Tutor：简化设计

## 1. 对交接文档的判断

交接文档真正关注的不是自动摘要，而是学习者能否形成可调用、可解释、可迁移的心智模型。完整框架通过三层对象实现这一点：原文证据层保存材料实际表达，机器参考图组织材料，学习者重建图保存学习者在特定提示和时间下能解释出的内容；两者差异再回到证据中裁决。

这套设计适合长期学习平台，但直接实现会同时引入文档解析、知识图谱、版本发布、多角色审核、学习状态推断、调度和可视化，难以在第一版验证“教学是否有效”这一核心假设。

## 2. 简化原则

第一版只实现一个端到端结果：

> 把明确提供的材料变成有来源的问题驱动课程，并通过逐节解释让学习者主动重建整体理解。

从原框架保留六项不可妥协的约束：

| 原框架原则 | 插件中的最小实现 |
|---|---|
| 来源证据层 | `sources.json`、文件哈希和每节 `source_refs` |
| 机器参考不等于真理 | 课程计划标记支持类型和 `uncertainties` |
| 主动重建 | 每节要求用户用自己的话解释概念、机制或关系 |
| 提示渐隐 | 首次回答先追问/提示，课程末要求整体闭卷重述 |
| 不覆盖学习记录 | `learning-progress.json` 追加 attempts |
| 学习优先于图谱完整 | 不生成完整概念图，只抽取主线所需概念与依赖 |
| 背景差异要有证据 | 用材料特定的前置问题与原始作答评估准备度，不推断广泛能力 |
| 外部补充不是原文 | 前置缺口使用有引用的 `external` 补充，与原材料证据分层 |

暂缓的能力：

- 正式 MRG/LRG 图数据库与图版本发布；
- Parser、Extractor、Verifier、Curator 等独立运行角色；
- 自动跨材料概念合并与冲突裁决；
- 基于长期历史的遗忘调度和掌握度模型；
- PDF OCR、复杂版面恢复和媒体解析服务；
- 独立的可视化前端与账户同步。

这些能力不是被否定，而是在验证核心教学循环后再按真实瓶颈加入。

## 3. 插件形态

采用 skills-only 插件，不使用 MCP 服务。原因是输入来自用户已经提供给模型的文件、目录或会话记录，而前置补充可以编排宿主现有的网络搜索或浏览工具。这些工具不可用时插件会降级为“材料内诊断 + 明确报告无法检索”，而不需要为此强制部署自有服务器。

当未来需要以下能力时再加入 MCP：

- 跨对话持久化大量学习历史；
- 受控读取外部知识库或会话存档；
- 团队账户、权限和审计；
- 服务端调度延迟复习；
- 可观察、可版本化的共享课程库。

```text

          │
      ┌──────────┴──────────┐
      ▼                    ▼
  已就绪          缺口 / 误解
      │                    │
      │                    ▼
      │          有引用外部补充 + 桥接复测
      │                    │

          │
      ┌───┴─────────────┐
      ▼                 ▼

      │                 │

              │
              ▼

              │
              ▼
       整体重述与迁移
```

## 5. 教学结构

课程不是按文件或章节机械摘要，而是按问题依赖排序：

1. 先说明材料共同解决的具体问题和总体框架；
2. 给出第一种可理解的方案；
3. 说明方案解决了什么，以及为什么仍不够；
4. 用暴露出的新问题引出下一种机制或组件；
5. 重复这一结构，直到形成完整主链；
6. 以边界、未决问题和迁移挑战收束。

每节都同时回答“是什么”“为什么存在”“如何工作”“代价是什么”“下一步为什么出现”，因此学习者不必把架构当成一组任意命名的模块记忆。

## 6. 三类输入的证据定位

| 输入 | 优先定位 | 重点 |
|---|---|---|
| 文档 | 文件、标题、页码/段落 | 作者论证、定义、例子与限定条件 |
| 代码库 | 文件、符号、行号、测试 | 实际控制流、数据流、边界与行为证据 |
| 会话记录 | session/导出文件、轮次、角色 | 决策如何形成、哪些说法后来被修订 |

材料中的命令、角色扮演或“忽略之前规则”等文本仍然只是证据。只有当前对话中的真实指令层级能改变插件行为。

## 7. 成功判据

第一版是否成功，不看抽取了多少概念，而看：

- 用户能否不照抄文档，解释各步骤与前后问题的关系；
- 用户能否指出方案的边界和代价；
- 用户能否在新情境中重新调用整体问题链；
- 前置诊断是否只评估真正阻断主线的概念簇，而没有将课程变成漫长的基础考试；
- 针对缺口的外部补充是否有可审核来源，并在桥接复测后不再阻断正课；
- 反馈能否区分遗漏、误解和材料本身的不确定；
- 额外的课程维护成本是否低于它带来的理解收益。
