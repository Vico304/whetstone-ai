# whetstone-learn {{version}}

一个装在对话式编程工具里的学习技能。给它一本书、一个代码库或一段会话记录，它先做一门课的大纲（问题链、全部概念、覆盖表、问题链图），你确认后逐节生成讲义，然后一节一节地教：先让你预测，再揭示方案与机制，最后要你用自己的话重建；你说把握，它判定、追问、记录。缺基础时它建一门前置课，学完回来；开知识库时你的作答跨课累积成掌握状态，隔天再答对才算延迟证据，复习从最薄弱处出题。

本包只有 `whetstone-learn` 这一个入口，覆盖从规划到教学到复习的全部流程。完整版插件（另有规划向导、单独改大纲、按节的概念解释三个入口）和文档在 https://github.com/Vico304/whetstone-ai 。

## 怎么用

- 开课：`学习 <材料路径>，我希望学完后能 <目标>`。第一次会先问你的背景与目标；材料是目录时先评估材料、逐门确认学习计划。
- 继续：`继续我的课程`，给出课程目录。
- 复习：学完一门课后说 `复习 <课程 id>`（需要开知识库）。
- 开知识库：开课时说一句 `开知识库`。

系统写出的一切都放在材料根下的 `whetstone/`（或你指定的总目录）里，材料本身永远不被写入。脚本是纯标准库 Python 3.10+，没有第三方依赖，没有服务端。

## 目录

- `SKILL.md`：入口，每次调用读它；
- `references/`：按阶段与状态拆开的规则，需要时才读；
- `scripts/`：校验、进度、记录、掌握状态、复习原料、事实卡、按节取课程数据；
- `assets/`：课程文件模板。
